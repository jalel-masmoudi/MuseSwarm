# Project Brief

**Request:** Build a Real-Time Engineering Sprint & Incident Priority Engine with weighted impact/urgency/effort scoring, SLA detector, interactive dark-mode UI (index.html), isomorphic core module (app.js), and unit tests (test.js).

## Architecture
- `app.js`: Isomorphic core engine (Node.js CommonJS export + browser `window.AppCore`).
- `index.html`: Interactive modern UI dashboard.
- `test.js`: Automated zero-dependency Node.js test suite using `assert`.
