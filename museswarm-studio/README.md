# MuseSwarm Studio — Frontend UI

Standalone React + TypeScript + Tailwind CSS v4 frontend for **MuseSwarm**, connected live to the MuseSwarm Node.js orchestration server (`http://localhost:4321`) and Meta's `Muse Spark Open` (`meta-models/muse-spark-open-1026`) on Baseten.

## Commands

```bash
npm install
npm run build   # Builds production bundle into ./dist (served by ../src/server.js on :4321)
npm run dev     # Starts Vite dev server on :5173 with proxy to http://localhost:4321
```
